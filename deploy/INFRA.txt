Build and run
Use Node.js 22 and Bun 1.4.5. Install with the existing bun.lock:
  bun install --frozen-lockfile --ignore-scripts
Build:
  npm run build:server
Run:
  npm start
build:server selects Nitro's node-server preset on Windows and Linux.
start runs node .output/server/index.mjs. Default port is 3000; set HOST and PORT as needed.
Proxy the complete app through infra HTTPS. Deploy the whole .output directory.
Rebuild in CI on the production OS/architecture; do not copy this Windows build to Linux.
The existing npm run build command remains available for the original Lovable workflow.
Local validation commands:
  node node_modules/typescript/bin/tsc --noEmit --pretty false
  npm test
  node scripts/smoke-server.mjs
Run the startup smoke after building; it temporarily serves only on localhost:4319 and checks
login/reset pages and the favicon. It does not verify authenticated workflows or migration.
