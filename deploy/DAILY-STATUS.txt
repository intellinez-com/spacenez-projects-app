Client daily status — 2026-11-20

Workflow
- The project list shows the latest team report and says when today's report is missing.
- Projects open on Daily status. Today, This week and So far filter published reports
  by work date. The reporting calendar is Asia/Kolkata; weeks start on Monday.
- Admins and assigned project partners choose Post daily update, confirm the work date,
  enter Work done / progress, and optionally add Next steps and Delays / blockers.
  A day without work can be reported explicitly with its reason.
- Clients read reports. Questions and feedback remain in Discussion and task comments.
- A missing report means the team has not posted one; it does not mean no work happened.
  The latest earlier report remains clearly dated when today's report is absent.
- Files shared in the selected period use their upload date, with the existing private
  bucket and signed opening. They are not claimed as attachments to a particular report.
- Overall progress and open task dates are the current task snapshot. There is no
  historical completion audit from which to calculate tasks completed on a given day.
- Reports refresh every minute while the screen is active and on window focus.
  The project Refresh button also checks daily reports.
- Published reports preserve their author, posting time and text. Post a follow-up
  report to correct earlier information. Existing reports cannot be edited/deleted
  through authenticated portal accounts.

Data and access
- public.project_daily_updates holds explicit report_date, work_done, next_steps,
  blockers, created_by and created_at. Multiple reports per work date are supported.
- RLS uses can_view_project for reads and can_edit_project for publishing.
  Client accounts cannot publish a team report, including through the direct API.
- The database stamps authenticated authors/times and rejects future work dates,
  blank work descriptions and oversized report fields.
- Existing comments have not been converted into daily reports. Fictional reports
  exist only in the isolated local preview and browser tests.
